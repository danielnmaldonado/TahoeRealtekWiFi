# Dual-band station implementation plan

Goal: operational 2.4/5GHz station paths for every verified dual-band family;
retain chipset-specific PHY/firmware/descriptor contracts and report physical
validation separately from source completion.

Architecture: net80211 owns scan/auth/association/WPA2 and IP controlled port.
Each chipset owns ROM, firmware, RF calibration, TX power, USB descriptors and
rate-control commands. Catalogue entries and offline helpers do not replace a
kernel station backend. The user authorizes direct source implementation.

## Constraints
- Preserve complete source delivery and mandatory ad-hoc signatures.
- No unsupported USB personalities, automatic reboot or SIP/AMFI changes.
- Clover is the loading method. RTL8192EU remains 2.4GHz-only hardware.
- Connected dual-band hardware is RTL8814AU2357:0106. Other chipsets require
  physical adapters before their WPA2/IP/throughput claims can be certified.

## Work items
- [ ] RTL8814AU: source-confirmed 5GHz power/eFuse tables, operating-channel
  switch, calibration, thermal handling, OFDM-only management/basic rates,
  SIFS/slots; PHY and host regressions first, then kernel integration and HAL test.
- [ ] RTL8812AU/8821AU: port firmware/ROM/power primitives, then board PHY,
  calibration, real TX/rate commands and net80211 attach with controlled port.
- [ ] RTL8821CU/8822BU/8822CU: source-confirmed rtw88 USB TX/checksum, then
  firmware/ROM/power/PHY and station integration, preserving chipset differences.
- [ ] RTL8192DU: boot/firmware/RF dual-MAC and PHY port from its own Linux driver.
- [ ] App: capability bit and band-aware eligibility/labels; SSID-only JOIN
  must not pretend that an observed BSSID is forced by clicking a row.
- [ ] Native/full tests, build/signatures, independent review, complete source
  archive and explicit incomplete-family/physical-validation matrix.

Review focus: missing 5GHz ROM; TX before calibration; CCK in5GHz; stale
calibration across bands; partial firmware failures; wrong chipset descriptors;
scan UI presenting unavailable station bands.
