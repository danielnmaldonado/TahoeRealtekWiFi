Application installed

Use Tahoe Wi-Fi USB from Applications. Do not run install.command after installing this package.

If the menu-bar icon has not appeared, open the app in Applications. Approve the service in Login Items & Extensions when macOS requests it.

Login startup opens the app after the user signs in; it does not connect before login or FileVault unlock. The kernel extension remains a separate component.

Installation messages appear in Installer's log and in /var/log/install.log, identified by TahoeWiFi.pkg.
