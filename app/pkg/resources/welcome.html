Tahoe Wi-Fi USB

This installer places the complete application and its privileged helper in /Applications/Tahoe Wi-Fi USB.app, with the permissions required by the service.

Before continuing, close the previous app using its Quit menu item. The installer does not force-quit processes.

Project target: Intel Mac, macOS Tahoe 26 or later. The kernel extension must be installed and approved separately.

This package does not install or load the kernel extension and does not change macOS security policies.
